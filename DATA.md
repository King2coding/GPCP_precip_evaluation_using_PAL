# Data guide

No observational data, satellite/reanalysis fields, collocation products,
generated figures, or manuscript files are distributed in this repository.

The workflows use several data categories:

- PAL precipitation observations;
- moored-buoy and atoll observations;
- OceanRAIN shipboard observations;
- GPCP and IMERG precipitation products;
- ERA5 and MERRA-2 reanalysis precipitation; and
- derived temporal/spatial matchups and evaluation statistics.

Access conditions and redistribution rights differ among these sources. Obtain
each dataset from its authorized provider and configure the relevant script's
input paths locally. The original rain-server directory remains the
authoritative working-data location for this project.
